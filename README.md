# Fly Sunnah Admin Panel

A static frontend concept for a future Fly Sunnah operations dashboard.

## Current state

The current `index.html` displays placeholder cards for bookings, customers, visa cases, and tasks. The values are intentionally blank; no operational data is generated or implied.

## Not implemented yet

- Admin authentication, roles, and session management
- Backend/API integration
- Booking, customer, visa-case, and task CRUD
- Database persistence and audit history
- Reporting, exports, and operational notifications

## Local preview

Open `index.html` in a browser or serve the repository root with any static file server.

Do not use this placeholder dashboard for live customer or business operations until authentication, authorization, backend integration, and data handling are implemented and tested.
